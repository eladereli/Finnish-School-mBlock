# Finnish-School-mBlock
Learning mBlock.cc

# What is mBlock.cc?

mBlock is a visual programming platform that helps students learn coding and robotics.

# How do we connect mBot2 to mBlock?

We connect mBot2 to mBlock using Bluetooth or a USB cable.

# What is the difference between block programming and Python programming?

Block programming uses visual blocks, while Python programming uses written code.

# How do we run a program using mBlock?

We connect the robot, create a program using blocks, and click the Run or Upload button.

# Why is mBlock useful for learning robotics?

mBlock makes programming easier and helps students understand how robots work.
